# Band-divergence allowlist.
#
# The propagation gate diffs every shared path between a band branch and dev, excluding the per-band plug
# (adapter/impl/**) and the per-band coordinate files, and expects no difference except the patterns below. A
# shared file that legitimately carries band-local code is listed here so neither the gate nor a future reader
# mistakes its difference for a lost fix or a bug.
#
# Format: gitignore-style per gitignore(5), one path pattern per line, blank lines and # comments ignored.
# Every pattern carries a # reason directly above it (checkBandDivergence fails on a pattern without one), so
# a shared reason across several files is repeated per line rather than written once over a group.
