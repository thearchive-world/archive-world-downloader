# Band-divergence allowlist.
#
# The propagation gate diffs every shared path between a band branch and dev, excluding the per-band plug
# (adapter/impl/**) and the per-band coordinate files, and expects no difference except the patterns below. A
# shared file that legitimately carries band-local code is listed here so neither the gate nor a future reader
# mistakes its difference for a lost fix or a bug.
#
# Format: gitignore-style per gitignore(5), one path pattern per line, blank lines and # comments ignored.
# Every pattern carries a # reason directly above it, naming why the file diverges per band and to what;
# checkBandDivergence fails the build on a pattern with no reason. Keep each pattern narrow: a directory-wide
# glob would mask an unintended divergence, which is the drift this register exists to catch.
#
# This is the seed of the known, stable members. Each port adds its own per-file band-local divergences as it
# creates them (the way the 26.x port records the players/ progress path), rather than pre-listing the bulk
# renames whose files no branch has diverged yet: the Identifier and ResourceKey.identifier() rename set, the
# band-fragile test assertions, and the keybind lang key. A broad glob for those would mask real drift or
# guess divergences that do not exist yet.

# the deeper bands thread through is all post-1.19), and no kept test binds data-driven tags.
